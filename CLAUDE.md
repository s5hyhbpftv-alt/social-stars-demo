# Social Stars AI — сайт направления

Статическая копия social-stars.ru на GitHub Pages плюс новое направление **Social Stars AI** в папке `ai/`. Сайт: https://s5hyhbpftv-alt.github.io/social-stars-demo/ai/

Всё, что вне `ai/` (главная, `contacts/`, `assets/*.js`), — собранный бандл старого сайта. Его не пересобираем, правим точечно, если нужно (например, контакты).

## Запуск локально

```bash
./tools/serve.sh                  # http://localhost:8123/social-stars-demo/ai/  (папка репозитория должна называться social-stars-demo)
cd tools/qa && npm install        # один раз; браузер: npx playwright install chromium
npm run check                     # вёрстка, ссылки и JS на всех страницах /ai/
```

Сборки нет: страницы — обычный HTML. После правки общих блоков запустите `python3 tools/include.py`.

## Структура

| Путь | Что это |
|---|---|
| `ai/*/index.html` | страницы направления: главная, 15 услуг, кейсы |
| `ai/*/campaign/index.html` | рекламные кампании: UGC, маркетплейсы, голос, тренажёр, перевод видео, поиск по документам, закупки |
| `ai/*/campaign/creatives/*.png` | баннеры кампаний, выгружаются скриптом |
| `ai/ai.css` | дизайн-система «Созвездие» и все компоненты |
| `ai/campaign.css` | общие стили страниц кампаний и макетов баннеров |
| `ai/ai.js` | меню, FAQ, форма заявки (открывает письмо на info@social-stars.ai), автозапуск видео |
| `ai/motion.js` | анимации на GSAP: графики, счётчики, схемы связей, линия времени |
| `ai/sky.js` | созвездия на canvas (первый экран, мини-созвездия) |
| `ai/vendor/` | GSAP 3.15 с плагинами ScrollTrigger, DrawSVG, MotionPath (без CDN) |
| `ai/img/`, `ai/video/` | сжатые медиа; `ai/img/ugc/` — кадры ИИ-героинь из проекта «Пчёлка» (`g*` — 9:19, `m*` — 3:4, `v-*` — обложки видео) |
| `tools/partials/` | общие блоки: `intro`, `header` (+ `brand-sprite`, `icons`), `cta`, `footer`, `scripts` |
| `tools/include.py` | вставляет партиалы между маркерами `<!-- @имя -->…<!-- /@имя -->` во все `ai/**/index.html` |
| `tools/gen/` | генераторы шести последних направлений и их кампаний (`gen_market`, `gen_voice`, `gen_trainer`, `gen_dub`, `gen_know`, `gen_proc`) |
| `tools/qa/` | проверки, скриншоты, выгрузка баннеров, нарезка кадров |
| `ai/DESIGN.md`, `ai/STRATEGY.md` | дизайн-план и стратегия с анализом мировых практик и источниками |

Страницы маркетплейсов, голоса, тренажёра, перевода, поиска и закупок **генерируются**: правьте генератор в `tools/gen/`, а не HTML, иначе следующий запуск затрёт правку. Остальные страницы (главная, первые 8 услуг, кейсы, UGC и её кампания) правятся вручную.

## Команды

```bash
python3 tools/include.py                          # после правки tools/partials/*
python3 tools/gen/gen_voice.py                    # пересобрать страницу и кампанию направления
cd tools/qa
npm run check                                     # все страницы: десктоп и 390px, ссылки, JS, «уменьшение движения»
node check-pages.mjs voice/ voice/campaign/       # выборочно
node export-banners.mjs voice                     # баннеры кампании → ai/voice/campaign/creatives/
node shots.mjs '{"voice/":[".vo-hero","#loss"]}'  # скриншоты блоков → tools/qa/out/
node crop-media.mjs <фото> <out.webp> 9x19 .55 420   # кадр для телефона (9x19), карточки (3x4), портрета (4x5)
```

`PW_CHROMIUM=/путь/к/chrome` — если нужен свой Chromium; `SS_BASE=…` — другой адрес сайта.

## Выкладка

GitHub Pages публикует ветку `main`. Работа идёт в ветке, затем PR в `main` и squash-merge. Перед PR `npm run check` должен пройти без ошибок. В описании PR — что изменилось и результат проверки.

## Дизайн: правила «Созвездия»

Подробно — `ai/DESIGN.md`. Главное:
- Светлый холодный фон, один шрифт Geologica, бронза — только звезда и главное действие.
- Одна «громкая» вещь на экран. Движение объясняет данные (график растёт, ответ печатается, данные идут по связям), а не украшает блоки. Никаких появлений блоков при прокрутке ради эффекта.
- Не использовать: почти чёрный фон с одним акцентом, капс-метки «01 / РАЗДЕЛ», стрелки «→» в кнопках, строки через « · », градиент на одном слове, одинаковые карточки с тенью.
- Мало текста, больше визуализаций. Каждая новая визуализация работает без JS и при «уменьшении движения» (показывается конечное состояние).
- Проверять на ширине 390 px: без горизонтальной прокрутки.

## Правила честности (обязательно)

- Демонстрационные данные подписывать как пример или условные.
- Не выдумывать отзывы, клиентов и результаты. Мировые цифры — только с источником и пометкой, что это не наши результаты.
- ИИ-аватары и героини помечены «ИИ‑аватар» / «ИИ‑модель»; ведущий не выдаёт себя за покупателя.
- Реклама — с маркировкой (erid). Голосовые звонки — по 41-ФЗ: маркировка, исходящие рекламные только с согласия.
